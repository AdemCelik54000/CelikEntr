CelikEntr - Site Portfolio
Description
CelikEntr est un site web portfolio personnel développé pour présenter mes services, projets et compétences en tant que développeur/freelance. Le site met en avant un design moderne et responsive, avec une gestion optimisée des médias (images et vidéos) via Cloudinary.

Fonctionnalités
Page d'accueil (Hero) : Présentation personnelle avec un appel à l'action.
Portfolio : Galerie de projets avec images progressives pour une meilleure performance.
Services : Liste des services proposés (développement web, etc.).
Contact : Formulaire de contact pour les clients potentiels.
Gestion des médias : Upload automatique vers Cloudinary, conversion HEIC et vidéos, génération de slugs.
Responsive : Design adapté aux mobiles et ordinateurs.
SEO optimisé : Sitemap, robots.txt, redirections Netlify.
Technologies utilisées
Frontend : React, TypeScript, Vite
Styling : Tailwind CSS, PostCSS
Backend : Fonctions Netlify (serverless)
Médias : Cloudinary pour le stockage et l'optimisation
Outils : ESLint pour le linting, scripts personnalisés pour la conversion de médias
